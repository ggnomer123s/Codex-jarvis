# Модель безопасности JARVIS

## Что нужно понимать

Codex с `--sandbox read-only --ask-for-approval on-request` может иметь ограничения на shell/file modifications. **Это НЕ означает, что MCP GUI-сервер не способен нажимать кнопки и менять состояние приложения.** Дополнительные инструкции AGENTS.md и Skill — не полноценная изоляция.

Не давайте Codex администраторские права, пароли, OTP, доверенные диалоги авторизации или бесконтрольный доступ к терминалу с sudo.

## Linux/Hypruse

При новой регистрации включаем `HYPRUSE_CONFINE=launched`, `HYPRUSE_STRICT=1`, `HYPRUSE_AUTH_GUARD=strict`, `HYPRUSE_JOURNAL=1`, `HYPRUSE_MARK=1`. Они сужают круг окон, блокируют ряд опасных ситуаций, пишут журнал и дают визуальный индикатор. Это защита в глубину; не абсолютная гарантия безопасности. Существующий MCP не меняется автоматически.

**Emergency stop:** `jarvis stop` или `uvx hypruse stop`.

## Windows 11/Windows-MCP

Новая регистрация создаёт локальный stdio MCP, исключая инструменты `PowerShell,Registry,Process,FileSystem,Clipboard`. Остальные UI tools, включая ввод, потенциально могут изменить систему, поэтому нужно отдельное человеческое подтверждение. Убедитесь, что Windows-MCP не включен как HTTP-сервер с широким сетевым доступом без аутентификации.

**Stop:** Ctrl+C/завершение Codex; его stdio MCP-процесс завершается вместе с клиентом.

## Отчеты и конфиденциальность

Linux watcher каждые 2 минуты рассматривает **failed systemd user services** и может передавать содержимое последних user-journal строк в Codex для текстовой read-only диагностики. Windows watcher по умолчанию выключен; при `-EnableMonitor` каждые 5 минут читает новые **Application Error** события и может отправить фрагменты событий в Codex. Логи иногда содержат IP, email, имена файлов и токены.

Перед публикацией отчета на GitHub удали личные данные и секреты. При сомнениях отключи монитор `jarvis monitor off`.

## Безопасный процесс

Наблюдение → проверка фактов → гипотеза → план минимального исправления → **согласие пользователя** → бэкап → пошаговое действие → проверка результата. При неожиданном изменении экрана или ручном вмешательстве остановиться. Никогда не отключать антивирус, UAC, polkit и system protection только для удобства GUI-агента.
